# AI 智能简历优化平台 —— 功能清单

本项目是一套基于大语言模型（LLM）与现代全栈 Web 架构打造的**智能简历优化平台**。系统围绕求职者在简历打磨过程中的核心痛点，提供简历解析、针对岗位 JD 的定向结构化改写（STAR 原则重构、量化数据注入、关键词匹配）、AI 预检、多轮对话微调、知识库自动沉淀、点数与支付中心及数据效能分析等完整闭环功能。

所有功能清单均来自实际源码实现与系统真实运行验证。

---

## 一、用户与账户体系 (Auth & User)

| 功能模块 | 子功能项 | 实际功能描述 | 对应接口/实现 |
| :--- | :--- | :--- | :--- |
| **用户注册** | 账号注册 | 支持用户名、邮箱、密码注册，密码采用 BCrypt 单向哈希加密存储 | `POST /api/auth/register` |
| | 新人权益 | 注册成功自动创建个人钱包，并获赠 3 个优化点数 | 事务级自动赠送与流水记录 |
| **用户登录** | 凭证认证 | 支持邮箱+密码登录验证，成功后签发标准 JWT 访问令牌（Bearer Token） | `POST /api/auth/login` |
| | Token 刷新 | 支持在 Token 到期前进行无缝续期换取新 Token | `POST /api/auth/refresh` |
| **用户中心** | 个人资料 | 查看用户基本信息（ID、用户名、邮箱、头像、注册时间、简历数、知识贡献数） | `GET /api/auth/me` |
| | 资料修改 | 支持用户自主更新用户名、邮箱、头像链接等信息 | `PUT /api/auth/me` |
| | 密码修改 | 支持验证旧密码后安全修改新密码 | `PUT /api/auth/password` |

## 二、简历管理与版本控制 (Resume Management)

| 功能模块 | 子功能项 | 实际功能描述 | 对应接口/实现 |
| :--- | :--- | :--- | :--- |
| **简历导入/上传** | 文本粘贴解析 | 支持多段落原始简历文本直接粘贴并统计字符数 | `POST /api/resume/upload` (Form/JSON) |
| | 图像 OCR 识别 | 支持上传 JPG / PNG 格式简历截图或扫描件，调用视觉模型提取文字 | `ocr_service.py` (`qwen-vl-max`) |
| **简历档案库** | 分页列表检索 | 支持按时间倒序分页查看个人历史简历，支持状态标签筛选 | `GET /api/resume/list` |
| | 简历详情查看 | 查看简历原始文本、优化后高保真 HTML、综合评分与多维量化数据 | `GET /api/resume/{resume_id}` |
| | 简历信息编辑 | 支持在线修改简历标题、求职城市、期望薪资、目标 JD、自定义标签 | `PUT /api/resume/{resume_id}` |
| | 简历安全删除 | 支持用户级权限校验，安全删除个人简历及关联历史记录 | `DELETE /api/resume/{resume_id}` |
| **版本追踪** | 版本谱系管理 | 支持基于 `parent_id` 维护简历多次优化的版本历史（v1, v2...） | `GET /api/resume/{resume_id}/versions` |
| | 历史版本切换 | 支持在详情页一键回溯并查看历次优化的演进对比 | 前端版本切换联动 |
| **导出与交付** | Word (.docx) 导出 | 基于 `python-docx` 将优化后的结构化 HTML 转换为标准 Word 格式下载 | `GET /api/resume/{resume_id}/export/docx` |
| | HTML / 打印 | 支持高保真网页预览与直接调用系统打印功能生成 PDF | 浏览器 Print API |
| **用户反馈** | 优化质量评分 | 支持用户针对单次优化结果进行 1-5 星评级并提交反馈文本 | `POST /api/resume/{resume_id}/feedback` |

## 三、AI 智能优化引擎 (AI Optimization Engine)

| 功能模块 | 子功能项 | 实际功能描述 | 对应接口/实现 |
| :--- | :--- | :--- | :--- |
| **AI 前置预检** | 匹配度分析 | 在正式优化前，根据求职城市、期望薪资、岗位 JD 及简历内容进行可行性预检 | `POST /api/optimize/check` |
| | 预检多轮问答 | 支持在预检阶段与 AI 进行上下文多轮对话，调整求职定位与补充信息 | 预检对话机制 (`precheckHistory`) |
| **深度结构化重构** | STAR 法则改写 | 自动将模糊的项目与工作经历按「情境(S) - 任务(T) - 行动(A) - 成果(R)」范式重塑 | `llm_service.py` + Prompt 模板 |
| | 量化指标增强 | 智能识别业务成果，补充与强化百分比、QPS、金额、时延等硬性量化数据 | 结构化输出解析 |
| | JD 关键词注入 | 提取目标岗位 JD 中的高频专业技能与核心术语，针对性植入简历匹配段落 | 关键词匹配统计算法 |
| | 优化强度调节 | 提供 1-5 级滑块控制改写幅度（轻度润色、标准优化、深度重构） | `strength` 级别映射调节 |
| | 综合评分与诊断 | 评估优化后整体匹配度（0-100分），生成修改摘要清单及优缺点分析 | `optimization_score`, `pros`, `cons` |
| **AI 对话微调** | 局部交互调整 | 在生成结果基础上支持 10 轮交互式微调，针对具体段落提出修改要求 | `POST /api/optimize/chat` |
| **知识库自动沉淀** | 优化模式提取 | 优化成功后自动提取本次案例中的通用高价值优化模式和行业关键词 | 异步知识抽取入库待审 |
| **安全防护** | 输出 HTML 消毒 | 对大模型生成的 HTML 内容进行白名单标签过滤与 XSS 防护，杜绝脚本注入 | `backend/utils/text_cleaner.py` |

## 六、支付中心与点数经济 (Payment & Wallet)

| 功能模块 | 子功能项 | 实际功能描述 | 对应接口/实现 |
| :--- | :--- | :--- | :--- |
| **个人钱包** | 余额与统计 | 查看当前剩余点数、累计充值点数及累计优化消费点数 | `GET /api/wallet` |
| | 点数流水明细 | 分页查询每笔点数变动的详细记录（类型、变动数额、变动后余额、时间、业务关联说明） | `GET /api/wallet/transactions` |
| **充值套餐** | 套餐展示 | 提供 3 档灵活充值方案（基础包 10 点 / 进阶包 50 点 / 专业包 100 点） | `GET /api/payment/packages` |
| **订单交易闭环** | 订单创建 | 选中套餐后生成唯一交易订单号，设置 15 分钟订单有效期 | `POST /api/payment/create` |
| | 支付模拟与确认 | 支持沙箱/模拟支付确认，支付成功后原子化增加点数并写入交易流水 | `POST /api/payment/{order_no}/confirm` |
| | 订单取消 | 支持用户主动取消未支付订单 | `POST /api/payment/{order_no}/cancel` |
| | 订单历史查询 | 分页查看个人历史充值订单状态（pending/paid/cancelled/expired） | `GET /api/payment/orders` |
| **点数消费机制** | 优化扣点与回滚 | 每次简历优化消耗 1 点；若优化过程异常，事务自动回滚，点数原路退回 | 事务原子性保障 |
