## 一、运行环境与配置

- **后端服务框架**：FastAPI 0.115.0 + Uvicorn 0.34.0

- **前端环境**：浏览器直接加载 `frontend/index.html`（静态挂载于 FastAPI 根路径）
- **自动化测试/截图驱动**：Playwright 1.62.0 + Microsoft Edge (Headless, 1920x1080)
- **服务监听地址**：`http://127.0.0.1:8000`
- **API 交互文档地址**：`http://127.0.0.1:8000/docs`

## 二、项目启动与部署步骤

1. **依赖检查与安装**：
   ```bash
   pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
   pip install pytest pytest-asyncio playwright
   ```
2. **启动后端服务**：
   ```bash
   python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
   ```
3. **访问前端页面**：
   打开浏览器访问 `http://127.0.0.1:8000` 即可加载全功能单页控制台。

## 四、AI 大模型调用验证情况 (客观如实记录)

- **调用协议与配置**：系统底层使用 OpenAI Chat Completions 兼容协议，通过 `httpx` 异步请求阿里云 DashScope Compatible API (`https://dashscope.aliyuncs.com/compatible-mode/v1`)。
- **调用状态说明**：
  > 📌 **客观记录**：当前源码 `settings.json` 中配置的 `ANTHROPIC_AUTH_TOKEN` 为未填写的空白占位符 `"   "`。当实际触发 `/api/optimize/check` 或 `/api/optimize` 调用外部大模型时，后端正确捕获了下游认证异常并返回 `502 Bad Gateway (Illegal header value b'Bearer   ')`。
  > 
  > 本系统针对外部 AI 异常具备完善的**事务原子性回滚机制**（点数不扣减、失败记录清理），并且在本地已预置真实优化简历样本数据（包含 STAR 法则重构、量化指标提升、维度分析等），前端渲染、状态流转、导出下载等所有后续链路均经过完整实测验证。

## 五、遇到的问题与必要低风险修复

按照任务执行原则，本次针对运行环境中的细微编码兼容性问题进行了低风险修复：

1. **`settings.json` 语法错误修复**：
   - **问题**：`settings.json` 第 3 行末尾缺失逗号 `,`，导致配置加载时报 JSON 解析异常并 fallback 到默认值。
   - **修复**：补齐逗号，确保配置项正确解析。
2. **Word 导出中文文件名 Header 编码兼容性修复**：
   - **问题**：`backend/routers/resume.py` 中的 `export_resume_docx` 端点在设置 `Content-Disposition` 响应头时，直接包含中文字符，触发 Python/Starlette HTTP Header 的 Latin-1 编码错误 (500 Internal Server Error)。
   - **修复**：采用 RFC 5987 / RFC 6266 标准规范，使用 `urllib.parse.quote` 编码中文字符串（`filename*=UTF-8''...`），使中文简历名称能够正常下载并显示。
