# 看板式项目任务管理系统 — 功能清单

## 一、用户与认证功能（AuthController / UserController）
* **用户注册**：支持用户名唯一性校验、密码与二次确认校验，后端使用 BCrypt 加密存储。
* **用户登录**：基于用户名与密码认证，登录成功后分发 JJWT 签名 Token，前端保存至 localStorage。
* **个人资料管理**：查看当前用户昵称、邮箱及注册时间，支持修改昵称与绑定邮箱（邮箱唯一性校验）。
* **密码修改**：验证原密码后更新为新密码（BCrypt 密码哈希重算）。
* **路由鉴权与拦截**：前端 Vue Router 导航守卫自动拦截未登录请求并重定向至登录页，后端 `LoginInterceptor` 拦截未授权 API 并返回 401。

## 二、项目管理功能（ProjectController）
* **项目创建**：输入项目名称创建项目，当前登录用户自动绑定为项目负责人（`owner`）。
* **项目列表分页**：分页展示当前用户参与的所有项目，展示项目名称、所属角色（负责人/成员）、成员数、任务数、活跃状态及创建时间。
* **项目名称维护**：项目负责人（`owner`）可修改项目名称。
* **项目归档管理**：项目负责人可执行项目归档（单向幂等操作），归档后从活跃列表中隐藏。
* **多项目快捷切换**：顶栏项目选择下拉框，支持在用户参与的活跃项目之间快速切换。

## 三、项目成员权限管理（ProjectController）
* **成员列表展示**：展示项目内全部成员的用户名、昵称与角色（`owner` / `member`）。
* **成员检索与邀请**：支持通过用户名检索系统用户并添加到项目。
* **角色动态分配**：支持在项目负责人（`owner`）与项目成员（`member`）之间动态变更角色。
* **成员移除安全防护**：支持移除项目成员，并内置“禁止移除唯一的项目负责人”防孤儿保护逻辑。
* **整表替换原子事务**：成员变更采用后端事务管理，保障数据一致性。

## 四、看板与任务管理（TaskController / 核心模块）
* **四列看板流转**：待办（`todo`）、进行中（`in_progress`）、已完成（`done`）、已阻塞（`blocked`）四状态列完整协同。
* **任务创建**：支持输入任务标题（必填）、任务描述（支持 Markdown 富文本编辑与实时预览）、优先级（低/中/高/紧急）、指派人、截止日期、项目标签关联、Sprint 关联。
* **拖拽排序与状态变更**：基于 VueDraggable / SortableJS 实现跨列拖拽更新状态，同列拖拽更新 `order_no` 顺序，后台批量持久化。
* **组合条件多维筛选**：
  * 按责任人（全部成员 / 具体成员）筛选
  * 按任务标题关键词全文模糊检索
  * 按截止日期起止范围筛选
  * 按项目标签筛选
  * 按 Sprint 迭代周期筛选
* **阻塞与解阻审批流**：任务标记为阻塞时必填阻塞原因（`block_reason`）；仅项目负责人（`owner`）具备解阻权限，解阻后恢复至进行中。
* **我的待办聚合（MyTasksPage）**：独立“我的待办”视图，跨项目汇总当前用户负责的所有任务，提供状态与优先级筛选及分页。

## 五、任务详情与审计活动流（TaskLogController）
* **任务元数据查看**：查看任务详细信息、负责人、优先级徽章、截止日期及所属 Sprint。
* **系统操作审计流水**：自动记录任务的创建、状态流转等操作日志。
* **任务讨论与评论**：项目成员可在任务详情中发表富文本评论，实时追加至协作讨论流。

## 六、标签管理功能（LabelController）
* **标签创建**：支持输入标签名称并使用取色器（ColorPicker）自定义标签背景色。
* **标签展示**：以彩色徽章直观渲染项目下所有自定义标签。
* **标签级联删除**：项目负责人可删除标签，后台自动级联清理任务与标签的关联映射（`task_label`）。

## 七、Sprint / 里程碑管理（MilestoneController）
* **Sprint 周期创建**：支持配置 Sprint 迭代名称与起止日期。
* **迭代状态自动推断**：根据系统当前日期与 Sprint 起止范围自动推断状态（未开始 / 进行中 / 已结束）。
* **任务与 Sprint 关联**：支持任务绑定到指定 Sprint，实现迭代周期划分。

## 八、甘特图与任务依赖管理（DependencyController / TaskDependencyService）
* **任务时间轴排期**：按日期时间轴直观渲染任务排期条。
* **关键路径高亮（Critical Path）**：支持根据任务依赖关系生成关键路径，并在甘特图中进行高亮展示。
* **任务 FS 依赖关联**：支持配置任务前置与后置依赖（Finish-to-Start）。

## 九、数据统计与图表可视化（StatsService / ProjectStats）
* **任务状态分布统计**：基于 ECharts 柱状图展示项目内各状态（待办/进行中/已完成/已阻塞）任务数量分布。
* **项目交付燃尽图（Burndown Chart）**：基于 ECharts 平滑折线面积图展示随时间推移的剩余任务数量变化趋势。
