# 看板式项目任务管理系统 — 技术栈与项目结构

## 一、技术栈与依赖版本清单

### 1. 后端技术栈（Spring Boot 3 + MySQL）
* **JDK 版本**：Java 21 LTS (`Oracle JDK 21.0.6`)
* **核心框架**：Spring Boot `3.5.14` (`spring-boot-starter-web`, `spring-boot-starter-validation`)
* **持久层框架**：MyBatis-Plus `3.5.15` (`mybatis-plus-spring-boot3-starter`, `mybatis-plus-jsqlparser`)
  * 使用 MyBatis-Plus `BaseMapper<T>` 及 `LambdaQueryWrapper<T>` 完成常用数据访问与条件查询
* **数据库**：MySQL `8.0.43（驱动 `mysql-connector-j 8.4.0`，`InnoDB` 引擎，`utf8mb4` 字符集）
* **认证与鉴权**：JJWT `0.13.0` 模块化引入 (`jjwt-api` + `jjwt-impl` + `jjwt-jackson`) + 自定义 `LoginInterceptor`
* **密码安全**：`spring-security-crypto 6.3.4` (`BCryptPasswordEncoder` 加盐哈希加密)
* **代码工具**：Lombok `1.18.46`
* **构建工具**：Apache Maven `3.9.15`

### 2. 前端技术栈（Vue 3 + Vite）
* **前端框架**：Vue `3.5.34`（Composition API + `<script setup>` 模式）
* **UI 组件库**：Element Plus `2.13.7` + `@element-plus/icons-vue 2.3.2`
* **构建与开发工具**：Vite `8.0.0` + `@vitejs/plugin-vue 6.0.2`
* **路由管理**：Vue Router `5.0.6`（HTML5 History 模式 + 全局导航守卫路由鉴权）
* **状态管理**：Pinia `3.0.4`
* **HTTP 客户端**：Axios `1.13.6`（封装请求拦截器挂载 JWT，响应拦截器统一处理业务 code 与 401 跳转）
* **数据可视化**：ECharts `6.0.0`（状态分布柱状图、燃尽图折线图）
* **拖拽排序组件**：VueDraggable `4.1.0` + SortableJS（实现看板卡片跨列流转与同列排序）

## 二、项目分层架构与通信链路

```
[前端 Vue 页面/组件] (ProjectBoardPage / ProjectSettingsPage / GanttPage 等)
       │
       │ 1. 用户交互触发业务操作
       ▼
[API 封装模块] (src/api/*.js)
       │
       │ 2. Axios 实例统一处理
       ▼
[Axios 请求拦截器] (src/api/request.js)
       │ 提取 localStorage 中的 token 注入 Header: Authorization: Bearer <token>
       ▼
[Vite 开发代理 / HTTP] (URL: /api/** -> http://127.0.0.1:8080)
       ▼
[Spring Boot 拦截层] (LoginInterceptor.java)
       │ 解析并校验 JWT 令牌签名，绑定 userId 到 request 属性
       ▼
[Controller 控制器层] (com.example.project.controller.*)
       │ @Valid 入参校验，统一调用 Service
       ▼
[Service 业务逻辑层] (com.example.project.service.impl.*)
       │ 权限校验（Owner/Member）、业务状态机检查、@Transactional 事务控制
       ▼
[Mapper 数据访问层] (com.example.project.mapper.*)
       │ 继承 BaseMapper<T>，使用 LambdaQueryWrapper 进行条件查询与数据持久化。
       ▼
[MySQL 8.0 数据库] (project_db, 10 张业务表)
       ▼
[统一响应封装 Result<T>] ({ code: 200, message: "...", data: T })
       ▼
[Axios 响应拦截器] (统一解包 data；401 自动跳转 /login；异常状态统一 ElMessage 提示)
       ▼
[Vue 响应式视图渲染]
```

### 1. 后端工程结构 (`backend/src/main/java/com/example/project/`)
* **`controller/`** (8 个控制器)：
  * `AuthController`：用户注册、登录
  * `ProjectController`：项目增删改查、归档、成员管理
  * `TaskController`：任务增删改查、看板拖拽排序、阻塞与解阻
  * `TaskLogController`：任务操作日志、评论
  * `LabelController`：标签增删查
  * `MilestoneController`：Sprint 里程碑管理
  * `DependencyController`：甘特图任务依赖管理
  * `UserController`：个人信息与密码管理
* **`service/` & `service/impl/`** (8 个业务接口与实现类)：
  * `UserServiceImpl`, `ProjectServiceImpl`, `TaskServiceImpl`, `TaskLogServiceImpl`, `LabelServiceImpl`, `MilestoneServiceImpl`, `TaskDependencyServiceImpl`, `StatsServiceImpl`
* **`mapper/`** (10 个数据访问接口)：
  * `UserMapper`, `ProjectMapper`, `ProjectMemberMapper`, `TaskMapper`, `LabelMapper`, `TaskLabelMapper`, `MilestoneMapper`, `TaskDependencyMapper`, `TaskLogMapper`，TaskTransitionMapper
* **`entity/`** (10 个实体类)：
  * `User`, `Project`, `ProjectMember`, `Task`, `Label`, `TaskLabel`, `Milestone`, `TaskDependency`, `TaskLog`, `TaskTransition`
* **`interceptor/`**：`LoginInterceptor` (JWT 鉴权拦截器)
* **`config/`**：`WebMvcConfig`, `MybatisPlusConfig`, `CorsConfig`
* **`common/`**：`Result<T>`, `BusinessException`, `GlobalExceptionHandler`

### 2. 前端工程结构 (`frontend/src/`)
* **`views/`** (8 个核心视图页面)：
  * `LoginPage.vue`：用户登录
  * `RegisterPage.vue`：用户注册
  * `ProjectListPage.vue`：项目列表
  * `ProjectBoardPage.vue`：四列任务看板（核心看板）
  * `ProjectSettingsPage.vue`：项目设置（基本信息、成员管理、Sprint 管理、标签管理）
  * `MyTasksPage.vue`：我的待办任务
  * `GanttPage.vue`：甘特图排期与关键路径
  * `UserProfilePage.vue`：个人中心
* **`components/`** (通用可复用组件)：
  * `ProjectStats.vue`：ECharts 任务状态分布图与燃尽图组件
  * `RichEditor.vue`：Markdown / 富文本编辑器与预览组件
* **`api/`**：`auth.js`, `project.js`, `task.js`, `label.js`, `milestone.js`, `dependency.js`, `user.js`, `request.js`
* **`router/`**：`index.js`（路由表与导航守卫）
* **`stores/`**：Pinia 全局状态管理
