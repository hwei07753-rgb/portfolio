# 智学伴 · 自律学习与AI互助平台 — 运行验证记录

## 一、真实运行环境配置

* **操作系统**：Windows 11 (x64) 专业版
* **JDK 版本**：Java 21.0.6 LTS (Oracle Corporation)
* **Node.js 版本**：v24.12.0（包管理器 npm 11.2.0 / pnpm 11.0.9）
* **MySQL 数据库**：MySQL 8.0.43（端口 3306，数据库名 `zhixueban`，字符集 `utf8mb4`）
* **小程序环境**：微信开发者工具 (WeChat DevTools) 最新稳定版
* **后端工程启动**：Spring Boot 3.5.14（Maven 执行 `mvn spring-boot:run` 或运行 `start_backend.bat`，监听端口 8080）
* **管理后台启动**：Vite 8.0.0 开发服务器（执行 `npm run dev`，监听端口 5174）
* **端到端网络链路**：前端通过 `http://127.0.0.1:8080/api/**` 统一访问后端服务，跨域与 JWT 鉴权全部打通。

## 三、核心业务功能实测验证记录

| 验证模块 | 验证动作与调用链路 | 预期响应与数据库变化 | 实测结论 |
| :--- | :--- | :--- | :---: |
| **后台安全登录** | 输入管理员账号 `admin` / 密码 `admin123`，发起 `POST /api/admin/login` | 校验 BCrypt 密文通过，签发有效 JJWT 并在响应头/Body 返回，前端自动跳转至概览大盘 | **通过** |
| **平台概览指标** | 管理后台访问 `/overview`，发起 `GET /api/admin/stats/overview` | 后端执行聚合 SQL，成功返回学员数、累计专注小时数、打卡数、AI调用量、帖子数 | **通过** |
| **番茄钟专注流** | 小程序端选择标签“考研刷题”，倒计时完成后调用 `POST /api/focus/finish` | `focus_record` 插入完成记录，学员积分 `coins` 自动增加 10 分，界面触发提示音 | **通过** |
| **白噪音播放** | 计时界面点击播放“雨声/自习室”白噪音 | 微信 `BackgroundAudioManager` 顺利拉取音频流，切到后台锁屏仍能保持播放 | **通过** |
| **打卡与AI复盘** | 小程序打卡页提交学习心得，调用 `POST /api/checkin/submit` | `checkin` 成功插入记录，触发双轨 AI 引擎生成复盘建议并原子写入 `ai_review` 表 | **通过** |
| **敏感词拦截** | 社区发帖输入含有“代考”、“挂科”文本，调用 `POST /api/posts` | 后端敏感词拦截器阻断，返回状态码 `1201`，提示“内容包含违规词”，DB 零脏数据 | **通过** |
| **社区发帖交流** | 小程序发布正常交流帖“求教快速排序最坏复杂度优化”，调用 `POST /api/posts` | `post` 表成功写入，社区对应分类 Tab 即时呈现新发布的帖子卡片 | **通过** |
| **一键召唤AI助教** | 在帖子详情页点击【🤖 召唤AI助教解答】，调用 `POST /api/posts/ai-reply` | 系统以虚拟用户 `999999` 身份生成专业分步解题思路并写入 `reply`，界面实时刷新 | **通过** |
| **内容合规审核** | 管理后台在打卡审核列表点击“违规下架”，输入原因并提交 | 打卡记录状态更新为 `2`（下架），同时在 `audit_log` 审计表记录管理员 ID 与操作原因 | **通过** |
| **敏感词库管理** | 管理后台添加违禁词“刷单”，调用 `POST /api/admin/sensitive-words` | 词库动态生效，再次发帖测试“刷单兼职”立刻被拦截，无需重启后端工程 | **通过** |
| **学员封禁风控** | 管理后台对违规学员账号点击“封禁”，调用 `PUT /api/admin/users/{id}/status` | 用户 `status` 更新为 `1`，该学员后续发起操作时均被系统全局拦截器拒绝 | **通过** |
