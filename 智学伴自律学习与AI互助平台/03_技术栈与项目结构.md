# 智学伴 · 自律学习与AI互助平台 — 技术栈与项目结构

## 一、技术栈与依赖版本清单

### 1. 后端核心架构（Spring Boot 3 + MySQL 8.0）
* **JDK 运行时**：Java 21 LTS (`Oracle JDK 21.0.6`)
* **核心框架**：Spring Boot `3.5.14` (`spring-boot-starter-web`, `spring-boot-starter-validation`)
* **持久层中间件**：MyBatis-Plus `3.5.15` (`mybatis-plus-spring-boot3-starter`)
  * 基于 `BaseMapper<T>` 与 `LambdaQueryWrapper<T>` 实现类型安全的条件查询与链式持久化。
* **关系型数据库**：MySQL `8.0.43`（驱动 `mysql-connector-j 8.4.0`，`InnoDB` 引擎，`utf8mb4` 字符集）
* **安全鉴权体系**：
  * **后台管理员**：JJWT `0.13.0` 模块化无状态令牌认证 + 自定义 `AdminAuthInterceptor`。
  * **密码哈希防泄露**：`spring-security-crypto 6.3.4` (`BCryptPasswordEncoder` 自动随机盐哈希算法)。
  * **小程序学员端**：微信登录体系（OpenID 校验与系统会话维持）。
* **AI 大模型接入**：
  * **双轨架构设计**：采用 Spring `RestTemplate` 封装标准 OpenAI / DeepSeek / 通义千问 Chat Completion API。
  * **超时自适应降级**：内置 5s 连接与读取超时熔断机制，超时或无 Key 时自动切换至本地专家规则模板。
* **工程辅助**：Project Lombok `1.18.36` + Apache Maven `3.9.15`

### 2. 学员移动端（微信原生小程序）
* **技术选型**：微信小程序原生开发（Native WXML + WXSS + JavaScript ES6+）
* **音频调度**：微信 `wx.getBackgroundAudioManager()` 统一调度，支持后台锁屏白噪音持续播放。
* **持久化缓存**：微信 `wx.setStorageSync` / `wx.getStorageSync` 维持学员状态与本地计时快照。
* **UI 风格设计**：自主构建“北欧森林自律风”设计系统，采用柔和绿与沉稳靛蓝配色的轻量圆角微拟物卡片。

### 3. 运营管理后台（Vue 3 + Element Plus）
* **核心框架**：Vue `3.5.34`（全面采用 Composition API 与 `<script setup>` 响应式语法）
* **UI 组件库**：Element Plus `2.13.7` + `@element-plus/icons-vue 2.3.2`
* **构建器**：Vite `8.0.0`（极速 ESM 开发调试与打包）
* **路由控制**：Vue Router `5.0.6`（HTML5 History 模式 + 全局 beforeEach 导航守卫）
* **状态中心**：Pinia `3.0.4`
* **网络请求**：Axios `1.13.6`（配置全局请求/响应拦截器，统一处理 401 令牌失效与异常反馈）

## 二、端到端全链路调用与分层架构

系统实现了“小程序端”、“Web 管理后台”与“Spring Boot 后端”的高内聚解耦架构：

```text
  ┌─────────────────────────┐          ┌─────────────────────────┐
  │   微信小程序 (学员端)    │          │  Vue 3 后台 (管理端)    │
  │ WXML / WXSS / 原生音频  │          │ Element Plus / Axios    │
  └────────────┬────────────┘          └────────────┬────────────┘
               │ HTTP 请求                           │ Authorization: Bearer <JWT>
               ▼                                    ▼
  ┌──────────────────────────────────────────────────────────────┐
  │                    Spring Boot 3 控制层                      │
  │  - AdminAuthInterceptor：后台管理员 JWT 签名合法性与状态校验    │
  │  - JSR-303 @Valid：请求参数规范化强校验                        │
  │  - SensitiveWordFilter：敏感词词库前置匹配拦截 (返回 1201)     │
  └──────────────────────────────┬───────────────────────────────┘
                                 │
                                 ▼
  ┌──────────────────────────────────────────────────────────────┐
  │                    Service 业务逻辑与 AI 引擎                │
  │  - CheckinService / FocusService / CommunityService          │
  │  - AIService 双轨路由：                                       │
  │    ├─ 主轨：OpenAI / DeepSeek / 通义千问 API 远程调用          │
  │    └─ 兜底：本地启发式导师寄语与题意点拨引擎 (5s 超时降级)       │
  │  - @Transactional：保障金币增加、打卡记录、AI复盘原子性落库   │
  └──────────────┬───────────────────────────────┬───────────────┘
                 │                               │
                 ▼                               ▼
  ┌─────────────────────────────┐  ┌─────────────────────────────┐
  │   MyBatis-Plus 持久层       │  │   外部 LLM 云端大模型        │
  │   10 张业务表 BaseMapper    │  │   DeepSeek / 通义千问 API    │
  └──────────────┬──────────────┘  └─────────────────────────────┘
                 │
                 ▼
  ┌──────────────────────────────────────────────────────────────┐
  │              MySQL 8.0 关系型数据库 (zhixueban)               │
  │  user, focus_record, focus_tag, checkin, ai_review,          │
  │  post, reply, admin, audit_log, sensitive_word (10张表)      │
  └──────────────────────────────────────────────────────────────┘
```
